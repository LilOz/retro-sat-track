# Rev F — one-stop AliExpress BOM

**USB-powered · 3.5-inch landscape · no touch required.** Buy the **MSP3525 no-touch** panel variant and a **44-pin ESP32-S3 N8R8 board with soldered headers**. The MSP3525 documentation currently names **ST7796U**, from the ST7796 family; this is a specific replacement for the earlier generic ST7796S proposal. Do not substitute a parallel Arduino shield, Pi display, bare FPC panel or smaller screen.

**Planning budget: £30–60 excluding filament, shipping and checkout tax adjustments, using an existing USB supply.** The former Adafruit display alone was budgeted at £35–45. Ranges below are per-build allowances, not verified offers; packs/minimum orders can cost more.

If nothing is on hand, add **£20–36 for two spools**, plus a supply if needed. No AMS required; each part has one colour. Slicer usage takes precedence over these material estimates. Basic soldering tools, an insert tip, multimeter and the P1S are assumed owned; the list includes build consumables.

**Fit gates:** panel PCB **98×55.5 mm**, nominal **92×49.5 mm hole pitch** from the family drawing; controller envelope **62.5×25.4 mm is provisional** for the candidate clone. Request exact seller drawings/photos if different. The display carrier and tray are replaceable. Touch and microSD are unused; an unavoidable SD socket does not justify buying a card.
