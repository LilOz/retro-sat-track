# Visuals

`terminal-concept.png` combines a front view exported from the Rev F Fusion model with an authored SVG screen concept. `ui-views.png` shows the three proposed 480×320 pages at their native pixel dimensions. The individual PNG/SVG views and editable composite SVG are included.

All screen numbers are illustrative. These images are not screenshots of running embedded firmware. CAD renders without UI overlays are in `../cad/generated-revf/`.

The overview globe uses the repository's bundled public-domain Natural Earth coastline data; see [attribution](../../backend/app/static/NOTICE.md). A 260-pixel globe spans about 39.8 mm on the specified 73.44×48.96 mm panel.
